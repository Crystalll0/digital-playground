# 序章 · 本机个人版

## 打开
双击同文件夹内的 index.html，使用电脑上的 Chrome、Edge 或 Safari 打开。无需安装、账号或联网。请固定使用同一个浏览器和同一个文件位置。

## 开始记录
- 右上角「新建任务」：只填名称即可保存。录入时可直接新增类别，保存后下次可选。
- 「安排日期」采用日历点选：单日安排选择一天并确认，不设置截止日期；「开始 — 截止」选择两天并确认，可选填具体截止时刻。发布日期收在「备注与发布日期」中。
- 重复默认关闭；选择「自选每周日期」才显示星期选项。开启「长期任务」才显示进度计算与阶段设置。关闭长期任务后保存会移除其阶段。
- 「批量录入」：粘贴每行一项的任务，选择统一类别和状态，生成表格后逐行修改。表格可横向滚动设置更多日期。
- 补录已完成任务时填写实际完成日期；日期不确定可以留空，只计入累计奖励。
- 「＋ 今日」将任务加入今日计划，不修改原截止日期。
- 在任务详情中添加阶段，选择等权、自定义权重或预计小时数。勾选阶段后保存，进度自动更新。任务整体完成时会将所有阶段标为完成。
- 重复任务完成后生成下一期；取消完成并重新勾选不会再次生成同一期。自选星期优先于普通周期。
- 专注计时达到一分钟后可以结束并保存；离开前请结束计时。也可以补记分钟数并关联任务。专注投入不会自动改变成果进度。

## 徽章
全局和类别分别累计：1、3、5、每 10 项、特殊数字节点。百位与千位采用更高等级的金属外观；节点持续延伸。图鉴可选择展示范围。

阶段、项目、专注、按时交付、每日完成、每周节奏、均衡推进和回归也有独立成就。徽章按当前有效记录计算；删除任务或改回未完成后，不再满足条件的徽章会退回未解锁，恢复完成记录后会重新解锁。回收站中的任务不参与统计。补录的数量徽章记录本次解锁日期，并标注补录；每日成就使用实际完成日期。

## 数据与提醒
设置中可以导出和导入完整 JSON 备份。导入会替换现有数据，请先备份。数据存在当前浏览器的本地存储，不会写入 HTML 文件，也不会上传。

本版本不含账号与云端同步，换设备可用备份手动迁移。数据结构带版本号，供未来同步版本迁移使用。

应用内提供到期和逾期信息。系统通知依赖浏览器支持和授权，并且页面需要保持运行；关闭页面后没有后台提醒。

## 验证范围
已通过脚本语法与核心逻辑检查：阶段权重、月末重复、自选星期、未知完成日期的成就归属、千位与特殊节点、重复解锁防重、视图生成及备份结构往返。
受当前预览环境限制，尚未完成浏览器视觉验收。首次使用建议添加一项测试任务，关闭并重新打开，确认该浏览器允许本地文件保存数据。

## 修改、删除与恢复
- 每行任务都有状态下拉菜单、编辑和删除按钮。已完成任务可以改回待开始或进行中，名称与日期也可继续编辑。
- 删除任务后，提示中可立即「撤回删除」。之后也可从「全部任务」或「设置与备份」打开回收站并恢复；回收站数据包含在备份中。
- 管理类别中可以删除类别；如果有任务，先选择迁移目标，最后点「保存更改」。至少保留一个类别。删除前可以点「取消删除」。
- 删除类别后，原类别徽章会移除，迁移任务按新类别重新计算徽章。
- 新版本记录任务整体完成前的阶段状态，重新打开时恢复该进展；旧版已完成任务没有这份历史，会保留现有阶段状态，可在编辑中调整。

## 类别统计
类别旁依次显示「总项目 / 待完成 / 已完成」，深棕色、红色、绿色分别对应三项。总项目指该类别全部有效任务，待开始与进行中均属于待完成；不含回收站记录。鼠标悬停可查看带文字的完整数量。

## 批量日期快捷填入
批量录入支持勾选「开始日期沿用发布日期」「完成日期沿用截止日期」。勾选后填入已有日期，后续选择来源日期也会自动复制；单独修改目标日期后，该行停止自动覆盖。取消勾选保留已填写内容，重新勾选会再次复制。来源为空时不清空目标日期。生成清单后所有行都可以复制完成日期；保存时仅已完成任务记录完成日期。

截止日期只选一天即可，具体时刻收在可选展开项里。批量表格保留逐行对照编辑，单条任务仍使用单日／日期范围选择器。

## 清单批量编辑
在全部任务或类别清单点击「批量编辑」，勾选任务，或「全选当前结果」，即可移动类别或删除所选。切换筛选条件会清空选择，避免操作隐藏任务。删除进入回收站，徽章同步重新计算。
