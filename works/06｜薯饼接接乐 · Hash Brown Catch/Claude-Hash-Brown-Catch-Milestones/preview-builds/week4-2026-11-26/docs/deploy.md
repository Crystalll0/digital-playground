# Deployment

The game is a static website, so it runs on GitHub Pages with no build step.

1. Repository → **Settings → Pages**.
2. *Source:* **Deploy from a branch** · *Branch:* `main` · *Folder:* `/ (root)` → **Save**.
3. After a minute the site is live at https://sd5913.github.io/Hash-Brown-Catch/
4. Put that link at the top of the README.

If Pages is disabled for the sd5913 organisation, ask the instructor; any static host works (the files are plain HTML, CSS and JS).

## Release check before each tutor meeting
- [ ] Live link opens and the game starts
- [ ] Sound plays after the first click
- [ ] Phone: touch drag works, nothing is cut off
- [ ] Shop: buying and equipping works; refresh keeps coins
