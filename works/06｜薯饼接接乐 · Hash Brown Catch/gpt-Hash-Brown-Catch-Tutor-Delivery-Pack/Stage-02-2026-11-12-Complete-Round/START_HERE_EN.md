# Stage 02 Complete round Start Here

Extract the full package. Python 3 is required. Run python3 Launch-Game.py on macOS or py -3 Launch-Game.py on Windows from this folder, or try the platform launcher. Keep the terminal open. Do not open the game HTML directly.

Adds a complete default 60-second round, burnt bites (−10), bombs (−20), Easy / Medium / Hard / Hell / Custom, gradual acceleration and local best scores by difficulty. Custom rounds offer 30 / 60 / 90 / 120 seconds. No permanent coins, shop, power-ups or rare pup.
