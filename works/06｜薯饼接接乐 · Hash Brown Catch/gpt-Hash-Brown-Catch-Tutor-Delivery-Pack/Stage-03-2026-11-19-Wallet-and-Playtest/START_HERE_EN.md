# Stage 03 Wallet shop and playtest Start Here

Extract the full package. Python 3 is required. Run python3 Launch-Game.py on macOS or py -3 Launch-Game.py on Windows from this folder, or try the platform launcher. Keep the terminal open. Do not open the game HTML directly.

Adds a permanent local wallet: each golden catch earns 2 coins; misses and hazards affect only the round score. The small shop offers Strawberry Social (120), Ketchup Cutie (60) and Minty Phantom (60), with the default bomb retained. Purchases equip automatically and survive reloads. No power-ups or rare pup.

Source is in Game-and-Website. Saves are separate by stage. For repository upload, copy that folder’s contents into game/ and merge templates from weekly-upload/EN or CN. Complete documentation, tests and tutor comments using real activity; do not overwrite earlier evidence.
