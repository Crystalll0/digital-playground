Run

Extract the whole ZIP. Install Python 3, then run Launch-Game.py. On macOS use python3; on Windows use py -3. Keep the terminal open. No API key, npm install or runtime internet connection is required.

Controls

Mouse or finger drag, arrows or A / D to move. Space or P pauses. Press R on the results screen to replay. The music button mutes sound. Audio begins after a user gesture.

Saving

Coins, cosmetics and best scores are saved in this browser and site origin, separately for each stage. They do not sync across devices or stages. Clearing site data removes progress. If storage is blocked, the shop warns that progress is session-only.

Scope

Cosmetics do not change gameplay. This build is prepared for final tutor review; final acceptance depends on team testing and tutor feedback. See the included documentation for credits, checks and pending evidence.
